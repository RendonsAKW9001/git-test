# Takeaways

## Use relative elements that move within normal flow.

## Use absolute inside a positioned parent.

## Use fixed for always visible elements ( like floating buttons ).

## Use sticky for navigation bars.

## Use z-index only when necesssary ( higher values go on top ).

## The display property contros how elements appear.

## Position controls where elements are placed.

## z-index controls layers.

## Overflow manages content visibility.

## Stuck, fixed and absolute have different use cases.
